Telegram 转发工具 v20（Telegram Forwarder v20）

免费开源的 Telegram 频道消息转发工具。一键把公开频道的消息转发到你的频道，支持 AI 洗稿、智能相册转发、关键词过滤与替换、定时批量、多账号多目标，Windows 下载即用。

下载最新版（Releases） 查看源码（GitHub）

Python 3.8+ ｜ MIT 许可 ｜ 无需装 Python 也能用（EXE 版）

主要功能

  • 消息转发：按消息 ID 区间从源频道转发到目标频道，支持 https://t.me/xxx/123 链接解析
  • AI 洗稿：接入 DeepSeek、OpenAI、Claude、Gemini、智谱 GLM、百川、通义千问、OpenRouter、Ollama 共 9 个平台，自动改写文案
  • 智能相册处理：按 grouped_id 分组转发相册，智能 / 简单 / 完整三种模式
  • 关键词过滤：包含关键词、删除关键词、替换关键词（原词=新词）
  • 批量与定时：批量任务、定时任务，长期自动运转
  • 多账号 / 多目标：一个程序管多个号、多个目标频道，克隆评论区
  • 隐藏发送者：转发不留 "Forwarded from"

怎么用

  1. 到 my.telegram.org 申请自己的 api_id / api_hash
  2. 下载并运行程序（EXE 双击即开，或 python telegram_forwarder_v20.py）
  3. 在「API 配置」里填入凭证并测试连接
  4. 在「登录」里输入手机号 + 验证码登录
  5. 在「转发」里填源频道、目标频道、消息 ID 区间，点「开始转发」

常见问题

问题解决
登录没反应检查 api_id / api_hash、网络（可能需要代理），看「日志」选项卡
AI 洗稿不工作检查 API Key 与 API URL，点「测试连接」验证
相册转发重复已知限制：相册无法直接改文案，当前方案是转发后再补一条洗稿文案
程序闪退查看目录下 error_log.txt，或在命令行运行看报错
